☁️ Subir a OneDrive — Microsoft 365

Cualquier técnico podrá subir reportes a OneDrive con un botón. Sin login por usuario. El admin configura esto una vez — gratis con Microsoft 365, sin necesidad de Power Automate Premium.

Verificando...

📋 Configuración — Azure AD App (15 minutos, una sola vez, incluido en M365)
  1. Ve a portal.azure.com → Azure Active Directory → Registros de aplicaciones → Nuevo registro
  2. Nombre: Visitas Técnicas Ecowatt → tipo de cuenta: Solo esta organización → Registrar
  3. Copia el Id. de directorio (inquilino) y el Id. de aplicación (cliente) — los necesitarás abajo
  4. Ve a Certificados y secretos → Nuevo secreto de cliente → pon caducidad 24 meses → Agregar → copia el Valor (solo se muestra una vez)
  5. Ve a Permisos de API → Agregar un permiso → Microsoft Graph → Permisos de aplicación → busca Files.ReadWrite.All → Agregar
  6. Clic en "Conceder consentimiento de administrador" → Sí
  7. En el campo Correo OneDrive destino escribe el email del usuario cuyo OneDrive recibirá los archivos (ej: admin@empresa.com)
  8. Completa los campos abajo y guarda

✅ Los archivos quedarán en OneDrive → Visitas Técnicas Solar del correo indicado

Todos los archivos se subirán al OneDrive de este correo, carpeta "Visitas Técnicas Solar".
